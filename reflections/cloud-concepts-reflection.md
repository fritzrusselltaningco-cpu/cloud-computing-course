# Cloud Concepts Reflection

Before taking this subject, I did not know that I was already using cloud computing almost every day. I only thought that cloud computing was about storing files online, but now I understand that it is much bigger than that. Many of the apps and websites I use every day are actually cloud services.

The first cloud service I use is Google Drive. It is a **Software as a Service (SaaS)** because I only use it through my web browser or phone without installing or managing any servers. It is also a **Public Cloud** because anyone can create an account and use it through the internet. I use Google Drive to save my school files so I can access them anywhere.

The second cloud service I use is Messenger. It is also SaaS because I only use the application to send messages and make calls. It is a Public Cloud because millions of people use it online. Messenger helps me communicate with my classmates and friends, especially when we have school activities and group projects.

The third cloud service I use is **Canva**. Canva is also **SaaS** because it provides online tools for making presentations, posters, and other designs. It is a Public Cloud since anyone can create an account and use its features through the internet. I often use Canva to make school presentations and assignments.

I also learned why Git and **GitHub** are important. Git helps save different versions of files, so if someone makes a mistake, it is easy to go back to the previous version. GitHub lets many people work on the same project without losing each other's work. It also helps organize files and keeps track of every change. I think these tools are very useful, especially for students and programmers who work together on cloud projects.

Overall, this activity helped me understand that cloud computing is already part of my daily life. It also taught me that Git and GitHub make teamwork easier and help keep projects organized.
